# 监控表格布局优化设计

## 目标

消除“距下一档位”与提醒设置列在窄窗口下的视觉重叠，同时让金额档位、单次变化阈值、批量编辑和未保存状态更容易辨认。

## 采用方案

保留高密度表格，不改动任何监控或提醒语义：

1. 金额列只显示金额与走势。
2. 把下一档进度放到“提醒状态”列，缩写为“下一档 +金额 · 差 金额”，允许正常换行。
3. 将原“本周最近提醒档位”改名为“提醒状态”，同列保留正负最近档位、当前状态、下一档和最近通知。
4. 每行提醒设置明确标为“金额档位”和“变化阈值”。
5. 批量编辑默认收起；勾选行后自动展开并显示已选数量。
6. 编辑后的行立即以高亮保存按钮和“未保存”说明提示；改回原值时提示消失。

## 未采用方案

- 将设置全部放入单独弹窗：窗口窄时最干净，但会增加逐行维护步骤。
- 改成卡片布局：移动端适配更好，但不利于桌面端一次比较多名代理。

## 验证

- 更新 Electron UI 冒烟测试，检查新列名、紧凑进度文本、阈值标签、批量编辑展开和未保存提示。
- 运行 Node 测试、Electron UI 流程和存储冒烟测试。
