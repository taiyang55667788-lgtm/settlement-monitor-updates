# 交收监控

长期维护和交接信息见 [MAINTENANCE_CONTEXT.md](MAINTENANCE_CONTEXT.md)。

跨平台桌面应用，可同时登录多个本级账号，监控各账号往下两级代理的“本周报表 → 应收下线”，按每个代理独立设置的提醒间隔发送 Telegram 通知。界面提供本周已提醒档位、最后成功读取时间及四种主题。

## 功能

- 多个本级账号并行监控，各自使用独立浏览器会话
- 安全码、账号、密码自动填写
- 分段式盘口登录配置界面，安全码在输入及重新编辑时都直接显示；密码仍不回显
- 数字验证码本地 OCR，失败时自动刷新重试
- 自动选择延迟最低的代理线路
- 兼容导航站随机域名跳转，不会把正常跳转误判为登录失败
- 显示代理线路测速结果、当前登录阶段和明确的失败位置
- 自动检测掉线并重新登录
- 监控本级账号的直属代理及这些直属代理的下级，不对本级合计金额发提醒；第二级报表读取失败时明确显示错误，不使用直属代理金额代替
- 每次读取都核对“本星期”日期范围与报表顶部显示的周期和代理层级；核对失败即停止，避免把“今天”数据当作本周数据
- 只读取明确标注“应收下线”的列；表头缺失或重复时停止提醒，不猜测其他金额列
- 两级代理以层级表格显示：直属代理展开后在下方显示二级代理；软件只展示提取出的数据，不嵌入盘口原报表页
- 各级代理可分别设备注和提醒间隔；备注同步到 Telegram 消息；以 0 为基准，正负各档在同一报表周内只提醒一次，重启后也不重复；一次跨越超过 20 档时合并为一条提醒，换周重新计数
- 每个代理显示本周正负已提醒档位和最后成功读取时间；读取失败时保留上次数据并标明过期，不根据过期数据发提醒
- 旧“上级交收”提醒记录自动归档，不混入“应收下线”；切换口径后的首次读取只发送一条已跨档位汇总
- 深蓝、石墨黑、浅色、高对比四种主题；应用金额正数蓝色、负数红色，Telegram 用蓝红圆点标识正负
- Telegram 一次性配对码绑定；原 Bot Token + Chat ID 手动方式保留在高级设置
- 敏感配置通过操作系统加密服务保存
- 启动时和每 6 小时自动检查版本，后台下载并提示重启安装

## 开发运行

需要 Node.js 22 或更高版本（测试使用内置 SQLite），以及 pnpm。

```bash
pnpm install
pnpm start
```

发布前先运行 `pnpm test` 和 `pnpm test:desktop`。后者会在隔离的模拟报表中验证后台页面下钻、同名二级代理、层级表格编辑，以及旧设置迁移；真实盘口登录和报表结构仍需在可访问的网站上核对。

## 打包

```bash
npm run build:win
npm run build:mac
npm run build:linux
```

Windows 安装包需要在 Windows 电脑上执行 `npm run build:win`；macOS 安装包需要在 Mac 上构建。生成文件位于 `dist`。

## 自动更新发布

Windows 版本默认从 Cloudflare R2 检查更新。推送 `v*` 标签后，GitHub Actions 会先运行测试，再构建安装包、便携版、`latest.yml` 和差分更新文件并发布。也可先手动运行工作流，仅生成供检查的 Windows 安装包，不推送更新。应用会自动比较版本号、下载更新，并在用户确认重启后安装。

发布新版本前先修改 `package.json` 的 `version`。正式分发 macOS 版本时需要使用 Apple Developer 证书签名；Windows 建议使用代码签名证书，避免系统安全警告。

## Telegram 配对

配对服务的部署说明见 [pairing-service/README.md](pairing-service/README.md)。Worker 地址已配置在 `electron/pairing-config.js`。应用中点击“生成配对码”→“打开机器人”→在 Telegram 点“开始”即可绑定；首次成功配对的私聊成为该机器人的唯一接收者。Bot Token 仅保存在 Cloudflare Worker Secret，不会进入安装包或桌面应用的本地设置；盘口账号、安全码和密码仍只保存在电脑本机。

如果配对服务不可用，仍可使用“高级设置”中的原手动方式：

1. 在 Telegram 联系 `@BotFather` 创建机器人并取得 Bot Token。
2. 先给机器人发一条消息。
3. 把 Token 填入应用，点击“自动获取 Chat ID”，保存后发送测试消息。

## 说明

应用只读取报表，不会下注或修改后台数据。网站页面结构若发生变化，可能需要更新 `electron/monitor.js` 中的页面识别规则。
